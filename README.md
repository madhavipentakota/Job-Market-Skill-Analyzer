# Job-Market-Skill-Analyzer



Job Market Skill Analyzer is a Data Science and NLP-based web application that analyzes job postings to identify the skills currently demanded by companies. The system extracts skills such as Python, SQL, Machine Learning, React, AWS, and Excel from job descriptions and provides interactive visualizations based on job role, location, and experience. It also allows students to enter their existing skills and identify the skills they are missing for their target career. Based on the skill gap, the system provides a personalized learning roadmap, such as a Data Science roadmap, and allows users to track their learning progress. The application is developed using React.js for the frontend, Python FastAPI for the backend, NLP and Data Science techniques for analysis, and PostgreSQL for data storage.
